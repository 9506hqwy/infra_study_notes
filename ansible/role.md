# ロール

タスクやテンプレートをまとめて再利用できる。

## ディレクトリ構造

ロールは 1 つ以上のディレクトリを含む。

| パス        | 説明                           |
| :---------- | :----------------------------- |
| `defaults`  | 変数の定義 (優先度低)          |
| `files`     | ファイル                       |
| `handlers`  | ハンドラの定義                 |
| `meta`      | ロールのメタデータ             |
| `tasks`     | タスクの定義                   |
| `templates` | ファイルの Jinja2 テンプレート |
| `vars`      | 変数の定義 (優先度高)          |

既定で *main* を含むファイル名を読み込む。

## 配置

ロールは下記に配置する。

- Ansible Collection
- プレイブックファイルと同じディレクトリにある *roles* ディレクトリ
- *roles_path* に含まれるディレクトリ
- プレイブックファイルがあるディレクトリ

## 使用

プレイレベルにロールを使用する。

```{literalinclude} ./samples/roles/01-play.yml
:language: yaml
:lineno-match:
```

```sh
ansible-playbook -i ./samples/inventories/05-connection.yml ./samples/roles/01-play.yml
```

```text
PLAY [Minimal Ansible Playbook] **************************************************************************************************************************

TASK [Gathering Facts] ***********************************************************************************************************************************
ok: [192.168.122.161]

TASK [01-role : Ping the host] ***************************************************************************************************************************
ok: [192.168.122.161]

PLAY RECAP ***********************************************************************************************************************************************
192.168.122.161            : ok=2    changed=0    unreachable=0    failed=0    skipped=0    rescued=0    ignored=0
```

タスクレベルにロールを使用する。

```{literalinclude} ./samples/roles/02-task.yml
:language: yaml
:lineno-match:
```

タスクを確認する。

```sh
ansible-playbook -i ./samples/inventories/05-connection.yml --list-tasks ./samples/roles/02-task.yml
```

```text
playbook: ./samples/roles/02-task.yml

  play #1 (all): Minimal Ansible Playbook       TAGS: []
    tasks:
      01-role : Ping the host   TAGS: []
      Dynamic Role Include      TAGS: []
```

実行する。

```sh
ansible-playbook -i ./samples/inventories/05-connection.yml ./samples/roles/02-task.yml
```

