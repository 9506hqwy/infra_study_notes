# プレイブック

yaml 形式のプレイブックファイルで処理対象ノードのパターンと必要なタスクを定義する。

[ansible.builtin.ping](https://docs.ansible.com/projects/ansible/latest/collections/ansible/builtin/ping_module.html#ansible-collections-ansible-builtin-ping-module)
モジュールを利用した最小限のプレイブックを定義する。

```{literalinclude} ./samples/playbooks/01-mini.yml
:language: yaml
:lineno-match:
```

```sh
ansible-playbook -i ./samples/inventories/05-connection.yml --list-tasks ./samples/playbooks/01-mini.yml
```

```text
playbook: ./samples/playbooks/01-mini.yml

  play #1 (all): Minimal Ansible Playbook       TAGS: []
    tasks:
      Ping the host     TAGS: []
```

## 実行

プレイブックを実行する。

```sh
ansible-playbook -i ./samples/inventories/05-connection.yml ./samples/playbooks/01-mini.yml
```

```text
PLAY [Minimal Ansible Playbook] **************************************************************************************************************************

TASK [Gathering Facts] ***********************************************************************************************************************************
ok: [192.168.122.161]

TASK [Ping the host] *************************************************************************************************************************************
ok: [192.168.122.161]

```
